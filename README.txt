WORD RUSH - arcade kelime oyunu

İngilizce -> Türkçe öğrenme mantığı korunur ama oyun akışı öndedir.
- Klasik, Blitz, Survival, Combo modları
- 3 zorluk
- 4 hızlı cevap seçeneği + 1/2/3/4 klavye kontrolü
- combo, çarpan, hız bonusu, gold word, boss round
- can, kalkan, +5 saniye, 2X puan
- kısa cevap sonrası İngilizce = Türkçe öğrenme ipucu
- sesli cevap ve telaffuz
- giriş yapan oyuncuda SQLite rekor/XP, misafirde reload sonrası sıfırlama

Kurulum:
python3 -m pip install -r requirements.txt
python3 web.py
http://127.0.0.1:5000
